Características

O que é o Obsidian?

Um aplicativo de base de conhecimento que trabalha com arquivos Markdown (.md) locais, ligados entre si por links.

Cada nota é um arquivo de texto comum dentro de uma pasta, chamada de vault (cofre). Não existe banco de dados próprio, nem formato fechado: a mesma pasta abre no VS Code, vai para o Git ou para qualquer outro editor.

Desenvolvido pela Dynalist Inc. e lançado em 2020, ele é mantido pelos próprios usuários (sem investidores) e virou referência em gestão de conhecimento pessoal (PKM).

📁 CompiuterZ/ ← vault = uma pasta comum └─ Casos de uso/ └─ UC10 - Candidatar-se.md --- tipo: caso-de-uso ator: Usuário --- # UC10 – Candidatar-se a Oportunidade Requisito: [[RF17]] Regras: [[RN13]], [[RN14]], [[RN25]] Pré-condição: detalhes exibidos em [[UC09]] #especificação #oportunidades
Características

Principais características

Local-first

As notas ficam no seu computador, em arquivos .md. Funciona sem internet e sem depender de servidor.

Links bidirecionais

Ligar a nota A à B com [[B]] cria também o caminho de volta (backlink). O conhecimento vira uma rede.

Gratuito

Grátis inclusive para uso comercial desde fev/2025. Só serviços opcionais (Sync, Publish) são pagos.

Extensível

Plugins oficiais (core) e milhares de plugins da comunidade: Git, Kanban, Tasks, calendários, temas…

Multiplataforma

Windows, macOS, Linux, Android e iOS, com a mesma interface.

Privacidade e formato aberto

Seus dados não ficam presos à ferramenta. Se o Obsidian sumir amanhã, os arquivos continuam legíveis.

Funcionalidades

O que dá para fazer

🔗 Links e backlinks

[[nota]] liga notas; o painel de backlinks mostra quem cita a nota atual.

🕸️ Graph view

Visualiza o vault como um grafo de notas e conexões.

🧾 Properties

Metadados em YAML no topo da nota (tipo, ator, status, data…).

🗃️ Bases

Plugin core (2025) que transforma notas em tabelas/cartões filtráveis, como um banco de dados.

🎨 Canvas

Quadro infinito para organizar notas, imagens e cartões com setas. Formato aberto JSON Canvas.

📐 Diagramas Mermaid

Fluxogramas, sequência, classes e estados escritos em texto e renderizados na nota.

🧩 Templates

Modelos prontos: ata de reunião, caso de uso, requisito. Padroniza o grupo.

☁️ Sync / Publish

Opcionais pagos: sincronização criptografada e site público das notas. Alternativa grátis: Git.

Nos próximos slides, cada funcionalidade aparece aplicada ao CompiuterZ, com demos que você pode clicar.

Análise

Vantagens e limitações para o grupo

Vantagens

  • Rastreabilidade RF ↔ RN ↔ UC automática, via links
  • Grátis e offline; texto puro versionável no Git
  • Documentação perto do código (pode viver no mesmo repositório)
  • Diagramas e tabelas gerados a partir do texto
  • Sem dependência de fornecedor (formato aberto)

Limitações

  • Colaboração em tempo real não é nativa (precisa de Git ou Sync pago)
  • Curva de aprendizado: Markdown, YAML, plugins
  • Não substitui ferramentas específicas: protótipos (Figma) e UML completa (Astah/StarUML)
  • Mermaid não tem diagrama de casos de uso nativo
  • Plugins da comunidade variam em qualidade e manutenção
Conclusão

Por que usar no CompiuterZ?

Nosso documento já é uma rede: cada caso de uso aponta para requisitos e regras. O Obsidian torna essa rede navegável, visual e verificável, sem custo e em arquivos que o grupo controla.

Especificação viva

Mudar uma regra mostra na hora todos os UCs afetados pelos backlinks.

Memória do grupo

Atas, decisões e justificativas ficam ligadas ao que motivaram.

Complementar

Funciona ao lado de Figma, Astah e Jira, como o "hub" que liga tudo.
